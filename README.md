# SlotJob

Schichten statt Stellen. Studis arbeiten einzelne Schichten (Slots), Betriebe besetzen sie schnell.
Prototyp live: https://slotjob.app

Uni-Projekt HackWG 26, Gruppe 24: Filip Neufeld, Filip Zelinskyi, Erik Dames, Jesper Feyerabend, Carl Tiegges.

## Ordner

```
site/index.html     der ganze Prototyp in einer Datei (HTML, CSS, JavaScript)
docs/plan.txt       unser Plan, jeder schreibt unter "Team:"
docs/kontext.md     ganzer Projektstand, z. B. zum Einfügen in einen KI-Chat
ideen/              eine Datei pro neuer Idee (Vorlage: ideen/VORLAGE.md)
```

## Ansehen

`site/index.html` im Browser öffnen. Kein Build, keine Installation.
Im Profil setzt "Zurücksetzen" die Demo-Daten zurück.

## So arbeiten wir

- `main` ist das, was auf slotjob.app läuft.
- Für Änderungen am Prototyp: eigener Branch `name/thema` (z. B. `erik/filter`), dann Pull Request auf `main`. Eine andere Person schaut kurz drüber.
- Text in `docs/` und `ideen/` darf jeder direkt auf `main` ändern.
- Aufgaben stehen in `docs/plan.txt` unter AUFGABEN: Namen eintragen, wer es macht.
- Jede Änderung auf `main` ist nach etwa 1 Minute auf slotjob.app live.
